# Reading a page

## What is around the text

- **On this page** — a table of contents built from the headings. Useful on a long runbook.
- **Linked from** — other pages that link here. Only pages you can read are listed.
- **Attachments** — files attached to this page.
- **Tags**, **Owner**, and when it was last updated and by whom.

If a page says it was *updated in the content folder*, somebody changed the file directly on the
server rather than editing it here. That is normal and supported.

## Banners you may see

Compendio puts a notice at the top of a page rather than letting you read something misleading
without knowing it.

| Banner | What it means |
|---|---|
| **This page is due for review** | Its owner is being asked to confirm it is still correct. Treat the content with mild suspicion until they do. |
| **You must confirm you have read this page** | Read it, then press the confirm button. See *Reviews and acknowledgments*. |
| **The source page has changed since this translation was written** | You are reading a translation whose original has since been edited. |
| **This page is only available in <language>** | There is no version in your language, so you are being shown the one that exists rather than nothing. |
| **Encrypted folder** | The file is stored encrypted on the server. Anyone with read access can read it here; only administrators can change it. |
| **Machine-translated, unreviewed** | A model produced this translation and no person has checked it. |

## Other languages

When a page exists in more than one language, an **Other languages** section lets you switch. The
versions are linked by a key in the page itself, so reorganizing folders does not break the link.

## Checklists

Checkboxes in a page are clickable. Ticking one saves immediately and appears in the page's history
like any other edit — handy for a runbook you are working through, but be aware that everyone sees
the same boxes.

## Images

An image in a page is shown scaled to fit the text, in its original proportions. Click it — or
select it with the keyboard and press **Enter** — to see it as large as your screen allows, with a
link to the file itself if the original is bigger than that.

An image that is also a link opens the link instead, as its author intended.

If you can edit the page, the enlarged view also offers **Delete the file**. That removes the
picture from the page *and* deletes the attached file, in one step, after asking you to confirm.

The edit to the page appears in its history like any other, **but the file itself is gone** —
history keeps versions of pages, not of attachments. Restoring an older version brings the picture's
line back with nothing behind it, so a deleted image has to be attached again.

## Diagrams

Pages can contain diagrams written as text. They render automatically when the page loads.

## If a page will not open

The message *"That page does not exist, or you do not have access to it"* is deliberately vague.
Compendio does not distinguish between the two, because telling you a page exists but is restricted
would leak the very thing the restriction is protecting. If you believe you should have access, ask
an administrator.
